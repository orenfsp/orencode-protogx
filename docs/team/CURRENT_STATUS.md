## Готовность

Рабочий демонстрационный прототип: четыре кабинета, соревнования/заявки/судьи/
результаты/публикации/история, разряды и категории, SMTP/inbox, реестры,
двухлетний XLSX, рейтинг, ручная сборная и экспорт. Исторический реестр уже
включён; ожидание PR #5 больше не является текущим блокером Д6/Д9.

Полная готовность ТЗ не заявляется:
- AC-09 partial: на стенде нет настроенных проверенных правил подсказок ЕВСК.
- AC-14 partial: генерация работает, соответствие заданным формам не принято.
- AC-18 partial для расширенного проекта: не завершена ручная приёмка всех новых форм.
- С3: проверка возраста и дисциплины тренерской связи есть; отдельного запрета
  по отсутствующей дисциплине спортсмена нет. Нужна трактовка бизнес-правила.
- Т2: справочник содержит шесть дисциплин, демо-соревнования/результаты — две.
- Д3 не меняет общий отчёт численности; Д6 показывает отдельные источники.
- Д4/Д7/Д8 используют вымышленные правила; Д12 partial по форме.
