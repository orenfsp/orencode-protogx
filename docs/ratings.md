# AC-12: рейтинги спортсменов

Продолжение mandatory part 1: русские названия «Чемпионат России», «Первенство России», «межрегиональное», «региональное» сопоставляются с версионированными базовыми корзинами. Для всероссийского статуса чемпионат и первенство различаются по типу; для кубка баллы не придумываются — нужна отдельная настроенная корзина `уровень:тип`. Текущее отстранение исключает спортсмена из выдачи рейтинга без перезаписи прежнего вклада. Исторические отстранения на дату соревнования продолжают учитываться при расчёте. В публичном рейтинге ФИО несовершеннолетнего заменяется псевдонимом; имя доступно владельцу, федерации и подтверждённому тренеру соответствующей дисциплины. Сырые персональные поля строки протокола в публичный breakdown не передаются.

Рейтинг хранится в приложении `backend/apps/ratings` и рассчитывается только по последней версии `ProtocolPublication` для каждого соревнования. Текущая строка вклада уникальна по `(athlete, competition, season, discipline)`; предыдущие публикации сохраняются как `is_current=false` с исходным JSON-снапшотом и ссылкой на использованные версии правила и протокола.

## Модели

- `RatingSeason` — календарный год сезона.
- `RatingRuleVersion` и `RatingPointRule` — версионированные правила, коэффициент и режим округления.
- `RatingContribution` — опубликованное доказательство места и начисленных баллов.
- `AthleteRating` — агрегат спортсмена по сезону и дисциплине.
- `AthleteRestriction` — федерационные приостановления/дисквалификации с датами и приватной причиной.

## Формула

`base_score = сумма баллов за места 1–3` из опубликованных протоколов. `prize_count` считает соревнования с местом 1–3. При `prize_count >= 2` применяется коэффициент `1.20`, иначе `1.00`. Результат округляется `Decimal.quantize(..., ROUND_HALF_UP)` до двух знаков.

Дефолтная таблица: Russian Championship `100/80/60`, Russian Junior Championship `80/60/40`, Interregional / district `60/45/30`, Regional `40/30/20`. Места ниже третьего баллов не получают без отдельной записи `RatingPointRule`.

## API

- `GET /api/v1/rating-options/`
- `GET /api/v1/ratings/?season=&discipline=&age_group=&min_rank=&page=&page_size=`
- `GET/POST /api/v1/rating-rules/` — только активная роль `federation` для записи.
- `POST /api/v1/ratings/recalculate/` — только федерация.
- `GET/POST /api/v1/rating-restrictions/` — только федерация; публичный ответ не содержит `reason_private`.

После публикации или перепубликации протокола пересчёт запускается транзакционно автоматически. Старые вклады помечаются устаревшими, новая текущая строка получает ссылку на последнюю публикацию, поэтому баллы не удваиваются. Ограничение проверяется на дату проведения соревнования, чтобы историческая публикация не менялась из-за более позднего решения федерации.
