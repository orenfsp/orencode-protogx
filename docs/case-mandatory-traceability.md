## Изменения относительно исходной инвентаризации

1. Адаптивные кабинеты: добавлены профиль РУСАДА, согласия, уведомления, ближайшие события, сроки и справочники федерации. 24 live screenshot/axe состояния: 4 экрана × 1440/768/390 × светлая/тёмная. Исправлены accessible name кнопки темы и контраст toast на первом кадре анимации. Канонический reference и extracted CSS неизменны.
2. Backend/контент: добавочные миграции notifications, profile RUSADA, audit role, coach status, registration_open, competition types и qualification correction ledger. Управление типами и сроками отчётов доступно федерации в кабинете. Проверены warning-free OpenAPI и migration drift.
3. Кабинеты: личный профиль с исторической организацией/муниципалитетом/дисциплинами, год начала, тренер, представитель только владельцу; дата/HTTPS URL сертификата РУСАДА и официальный сайт. Отзыв/возобновление согласия с новой записью истории и проверкой представителя для minor. Связи suspended/ended/resume с причиной и аудитом. **Поиск спортсмена тренером остаётся по известному email; отдельный поиск по имени в реестре не добавлен.**
4. Соревнования: явное закрытие/повторное открытие приёма, положение DOCX, фильтр по возрастной группе и подбор по возрасту на дату соревнования, личная PDF/DOCX выписка из сохранённой версии без других участников. Протоколы и полные публикации остаются приватными для федерации.
5. Квалификации/уведомления: журнал прежних/новых реквизитов с причиной и UI исправления федерацией; разряды проверяются в дисциплине результата; непроверенные ЕВСК-правила не дают подсказок. Транзакционный inbox/outbox, SMTP adapter, Mailpit capture, 5 попыток/backoff, row-lock worker, дедупликация, роль/coach scope recheck; напоминания registration/rank/category/report/1 февраля. Production delivery не проверена.
6. Численность: сохранена историческая методика; новый live тест перевода повторяем на изменённой демо-базе. Реальные файлы проверяются openpyxl, API/UI значения сопоставляются.
7. Рейтинг/сборная: текущее отстранение исключается при чтении; исторический вклад не перезаписывается. Русские названия уровней и федеральный чемпионат/первенство имеют раздельное соответствие; баллы кубку не выдумываются. Публичное ФИО minor замаскировано, сырые персональные поля протокола не выдаются. Существующий ручной отбор/документы сохранены.
8. Документы: добавлен XLSX отчёт выступлений по последним версиям, доступ владельцу/федерации/подтверждённому тренеру только его дисциплин; защита formula injection, пустой отчёт, метаданные публикации. Реальные DOCX/XLSX разобраны, PDF отрендерены и осмотрены. Все формы остаются демонстрационными до сверки.

- PDF с.5 допускает email, Telegram **или** MAX. AC-10 отдельно требует email. Выбран SMTP, поскольку это принятое проектное ограничение.
- PDF с.9 не фиксирует палитру/шрифты. AC-17/18 дополнительно обязывают сохранять reference HTML и его CSS/hash.
- PDF с.4 допускает формат по типу документа, а не каждый документ во всех трёх форматах.
- Напоминание «до 1 февраля» обязательно (с.2), автоматический расчёт премий D8 факультативен (с.8).
